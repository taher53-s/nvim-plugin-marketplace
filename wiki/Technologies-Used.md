# Technologies Used

## Programming Languages
- **Lua (LuaJIT):** The foundational logic scripting framework processing all architectural logic, indexing, algorithms, and application states.
- **VimScript:** Interfaced natively via Neovim instances strictly for triggering initialization commands.

## Frameworks & Platforms
- **Neovim API Engine (C-Layer):** Targeting `vim.api`, `vim.ui`, and `vim.uv` (libuv) asynchronous process pools.
- **GitHub REST API v3:** Operates flawlessly supplying dynamic, raw JSON metadata concerning software projects, stars, descriptions, and branch statuses globally.

## Core Tooling & Binaries
- **Git:** The backbone protocol for orchestrating codebase tracking and fetching operations locally.
- **Curl:** The networking bridge for communicating safely over HTTPS protocols inside internal background environments avoiding external libraries.
- **POSIX Regex Engine:** Executing heavy string pattern matching arrays directly parsing operating system console outputs.
